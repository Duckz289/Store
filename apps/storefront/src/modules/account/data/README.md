# Vietnamese address data

`vietnamese-administrative-units.json` is a vendored snapshot of the Vietnamese-only simplified dataset from:

https://github.com/thanglequoc/vietnamese-provinces-database

Snapshot: 2026-07-25. The repository documents 34 provincial units and ward/commune records in the current two-tier administrative structure. Refresh this file when the upstream administrative data changes. The data is used only for client-side address selection; Medusa remains the source of truth for customer address persistence.
